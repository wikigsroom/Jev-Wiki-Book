# 欢迎使用 JEV

这是 JEV 桌面版自带的示例文档。你可以把自己的 PDF、Word、Markdown、文本和 HTML 文档放入当前 JEV 文件夹，然后点击“重新扫描”。

默认文档目录是便携 EXE 同级的 JEV 文件夹。点击页面右上角“切换目录”，可以选择本机的其他文件夹。

JEV 使用本地 NanoJev 和本地 OCR 处理文档。检索时返回原文段落与来源，不使用 Claude，不调用云端 API，也不生成或改写回答。

便携版的数据和日志保存在 EXE 同级的 JEV-data 文件夹。更新 EXE 时保留这个文件夹即可保留文档索引和设置。

本地模型保存在 EXE 同级的 JEV-models 文件夹，运行环境保存在 JEV-runtime。请复制整个便携目录；关闭桌面窗口后，本地检索服务也会退出。

首次检索需要加载模型，通常比后续检索更慢。当前便携版使用 CPU FP32 推理，不要求 NVIDIA 显卡。
