JEV 0.5.0 是完全在本机运行的 Windows x64 文档证据检索桌面版。选择文件夹并提问，返回原文段落，附来源定位与阅读器高亮。内置社区 NanoJev、OCR 和独立 Python 环境，不需要 Claude、API Key、Python/Node 安装或 CUDA。

### 首次使用

下载两个 `.zip.001` / `.zip.002` 分卷、`JEV-0.5.0-downloads.json` 和 `Merge-JEV.cmd`，放在同一目录。双击合并脚本，或从该目录的终端执行：

```powershell
.\Merge-JEV.cmd
```

脚本校验并合并出标准 ZIP。完整解压后双击 `JEV-0.5.0-windows-x64-portable.exe`，保留同级 `JEV-runtime` 和 `JEV-models`。单独的 EXE 用于已有完整便携目录的情况，不能单文件离线推理。

默认读取同级 JEV 文件夹，可用页面“切换目录”或 Ctrl+O 选择其他本机路径。解压内容约 3.51 GB；建议 16 GB 内存与至少 10 GB 可用磁盘空间，以容纳分卷、合并 ZIP、解压目录和启动临时文件，文档库另计。

### 验证与限制

已在 Windows 11 x64 实测启动、真实 NanoJev 段落检索、OCR、目录切换、设置保存、异常恢复和退出清理；22 项 Python 与 3 项 Node 回归通过。包内文件逐份校验，附件提供 SHA256。未在另一台干净机器或 Windows 10 实测，EXE 未签名。
