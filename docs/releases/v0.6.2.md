# JEV 0.6.2 · 明确程序职能的大驼峰命名

桌面程序改名为 **JevDocumentSearchDesktop**，负责本机文档目录选择、扫描、原文检索和阅读，可选开启受限 Web 查询。独立服务器程序改名为 **JevDocumentAdminQueryServer**，一次启动文档管理端与受限查询端，运行时不使用 Electron。

| 平台与用途 | 首次安装下载 |
| --- | --- |
| Windows x64 桌面文档检索 | `JevDocumentSearchDesktopWindowsX64Portable-0.6.2.zip` |
| Windows x64 文档管理与查询服务器 | `JevDocumentAdminQueryServerWindowsX64-0.6.2.zip` |
| Linux x86_64 文档管理与查询服务器 | `JevDocumentAdminQueryServerLinuxX64-0.6.2.tar.gz` |

程序名、包内目录、下载附件、构建脚本和安装命令同步改名。服务程序新增 `--version`，显示 `JevDocumentAdminQueryServer 0.6.2`。服务器包内执行 `JevDocumentAdminQueryServer.exe` 或 `./JevDocumentAdminQueryServer`。

仍使用本地 CPU NanoJev 与 OCR，只返回原文段落。首次安装还需 [v0.6.0 的共用模型附件](https://github.com/wikigsroom/Jev-Wiki-Book/releases/tag/v0.6.0)；已有完整 `JEV-models` 可直接复用。单独桌面 EXE 需要同版 `JEV-runtime`，不能独立代替首次安装 ZIP。

升级前退出旧程序、备份数据并替换完整程序运行环境；保留 `JEV-models`、`JEV`、`JEV-data` 或服务端 `server_data`。服务快捷方式改为新名称，账号与共享设置格式不变。默认管理端 18765、查询端 18766；初始账号 `admin` / `Jev-Change-Me-2026!`，首次登录强制改密。

[安装、校验与升级说明](https://github.com/wikigsroom/Jev-Wiki-Book/blob/v0.6.2/docs/DISTRIBUTION_0_6_2.md)。源码分支为 `main`（桌面）与 `cli`（服务器）。Windows EXE 未签名，Linux 构建基线为 Ubuntu 22.04 x86_64。
