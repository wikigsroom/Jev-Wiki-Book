# JEV 0.6.0：桌面共享与独立管理/查询服务

Electron 设置现在可以启用独立 Web 查询端，默认端口 18766。Web 用户只能查询桌面端已建立的当前文档库，不能查看或修改目录、上传、删除或下载整份文件。

新增 `cli` 分支，提供无需 Electron 的 Windows x64 / Linux x86_64 原生程序。启动后同时运行管理端 18765 与查询端 18766。管理端默认仅本机，初始账号 `admin` / `Jev-Change-Me-2026!`，首次登录必须改密。管理员可以扫描多个目录、选择允许查询的文档和撤回访问；查询端仅显示问题与命中原文段落。

## 下载与运行

- Windows 桌面端：`JEV-0.6.0-windows-x64-app.zip`。
- Windows CLI：`JEV-cli-0.6.0-windows-x64.zip`。
- Linux CLI：`JEV-cli-0.6.0-linux-x64.tar.gz`。
- 共用模型：`JEV-models-0.6.0.zip.001`、`.002`，配合 downloads.json 与合并脚本。已有 0.5.0 模型可直接复用。

保留程序包内的 `JEV-runtime` 或 `_internal`；将 `JEV-models` 放在入口同级。模型未包含在单独 EXE 中。全部原生 CPU FP32 运行，无需 Python、Node、GPU、Claude 或 API Key。[完整安装、合并与 SHA256 校验步骤](https://github.com/wikigsroom/Jev-Wiki-Book/blob/main/docs/DISTRIBUTION_0_6.md) · [CLI 部署说明](https://github.com/wikigsroom/Jev-Wiki-Book/blob/cli/docs/CLI_DEPLOYMENT.md)。

## 验证与边界

Windows 和 Ubuntu 22.04 原生构建均通过回归、真实 NanoJev CPU 查询、Word/PDF/OCR，以及管理端登录、改密、扫描、开放/撤回和查询页桌面/窄屏测试。[构建与验收记录](https://github.com/wikigsroom/Jev-Wiki-Book/actions/runs/35770689878)。CLI 二进制构建源码为 `229f70dd67081954840e571b1e3961a2ad272d70`，对应 `cli-v0.6.0` 标签。

Electron 便携 EXE 已在 Windows 11 实际启动与关闭；发行目录中的独立后端通过共享开关、重启持久化、访问隔离和真实模型查询测试。本轮未完成 Electron 设置窗口逐项点击验收，详见仓库验证记录。

原始 NanoJev 权重、精度与检索算法保持不变。系统返回原文，不生成总结；游戏训练权重尚无通用文档语义检索质量保证。建议 16 GB 内存；Windows EXE 未签名，Linux 基线为 Ubuntu 22.04 x86_64。CLI 当前为单管理员和一份共享文档范围，查询端无个人账号，适合由企业内网或认证网关控制访问。
