# JEV 0.6.1：权限、并发与退出流程修复

本次逐项复查 Electron 共享、CLI 管理端/查询端及原生交付需求，修复了查询取消后的并发控制、停止共享时的锁竞争、Linux 同端口重启、索引退出收尾、大批量文档授权、多实例 Cookie 冲突，以及排队写操作的会话校验。持久化凭据和授权范围损坏时明确拒绝启动；缺少本地 NanoJev/OCR 时 --check 返回非零。

Electron 增加共享设置读取失败的重试入口。管理页面明确提示尚未开放的新索引版本，查询页面刷新可用状态。全部保持本地 CPU FP32、原始社区 NanoJev 权重与原文段落输出。

## 下载与升级

- Windows 桌面版：JEV-0.6.1-windows-x64-app.zip。
- Windows CLI：JEV-cli-0.6.1-windows-x64.zip。
- Linux x86_64 CLI：JEV-cli-0.6.1-linux-x64.tar.gz。

保留 JEV-runtime / _internal 和 JEV-models。单独 EXE 不包含 Python 及模型。升级保留 JEV、JEV-data / server_data 和自选文档目录；凭据、索引和授权无需清空。模型复用 [v0.6.0 共用模型分卷](https://github.com/wikigsroom/Jev-Wiki-Book/releases/tag/v0.6.0)，已有完整模型无需重新下载。[完整安装与升级说明](https://github.com/wikigsroom/Jev-Wiki-Book/blob/main/docs/DISTRIBUTION_0_6_1.md)。

CLI 默认管理端 127.0.0.1:18765、查询端 0.0.0.0:18766。新数据目录的初始账号 admin / Jev-Change-Me-2026!，首次强制改密。Electron 共享默认关闭，可在设置启用 18766 查询端。
