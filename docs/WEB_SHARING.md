# Electron 与 Web 查询端

JevDocumentSearchDesktop 的设置窗口提供“浏览器查询端”：勾选启用，选择端口和范围，点击“应用查询端设置”。默认关闭；默认端口 18766，可选 1024–65535。端口占用时显示错误，不启动其他端口或其他服务。

“仅本机”绑定 127.0.0.1；“局域网”绑定 0.0.0.0，访问者使用运行电脑的局域网 IP。应用不修改防火墙。查询端没有账号系统，能连接端口的人均可查询当前开放内容，请由网络边界限定访问者。

Web 页面只有问题输入、原文结果、来源名称与段落定位。后端只提供 GET /api/health 和 POST /api/query；不提供目录列表、修改路径、上传、删除、完整文档下载、OCR 图片和管理接口。公开响应不会包含磁盘路径、索引标识、内部异常或候选调试信息。

桌面端扫描完成后，Web 查询使用当前已建立的文档库。切换库、更新索引、停用共享时，在途查询会重新检查访问版本，旧版本结果不会作为新查询返回。已被用户阅读或复制的内容无法远程收回。

两个入口共用同一模型实例，CPU FP32 推理。查询端一次接受一项模型查询，繁忙时返回 429；过大的请求和跨来源浏览器请求会被拒绝。关闭 Electron 时其 Python 后端与附属 Web 监听器一并退出。

此入口提供原文证据查询，不改变现有 NanoJev 游戏权重与 BM25 的检索逻辑。
